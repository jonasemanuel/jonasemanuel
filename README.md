### 🚀 About Me

Senior Fullstack Engineer with **11+ years of experience** designing and building scalable, resilient, and secure backend and frontend systems — including platforms serving millions of users in retail and media.

I focus on solid software engineering fundamentals: **Domain-Driven Design**, **Clean Architecture**, and **Test-Driven Development**, applied to distributed, microservices-based systems. I design both **synchronous** (REST, GraphQL) and **asynchronous** (SQS, SNS, RabbitMQ, event-driven) communication between services, and build **ETL / data pipelines on AWS (including AWS Glue)** to move and transform data at scale.

I've owned platforms end-to-end — architecture, Design Docs, ADRs — and led engineering teams at companies like **Grupo Boticário**, **Globo / Globoplay**, and **Loft**, with a strong emphasis on observability, code quality, and reducing bug escape rates through mentoring and review process improvements.

- 🏗️ Architecture: Domain-Driven Design, Clean Architecture, Microservices, Event-Driven Systems
- 🧪 Testing: TDD, unit/integration testing, CI/CD quality gates
- 🔄 Communication: sync (REST, GraphQL) and async (SQS, SNS, RabbitMQ) messaging patterns
- 📦 Data: ETL pipelines with AWS Glue, S3-based data flows
- 📈 Observability: New Relic dashboards for infra metrics and logs
- 🌎 Open to international remote opportunities as a Senior Software Engineer
